### ⚡ What I do

**🌐 Networks**
- Design and deploy **MikroTik / RouterOS** networks for hotels and businesses
- **Load balancing** and **failover** across multiple ISP lines (incl. Starlink)
- **VPN**: WireGuard remote access with split tunneling
- **PPPoE passthrough** on ISP routers, so the edge router gets the public IP
- VLANs, staff / guest isolation, hotspots, centrally managed WiFi (CAPsMAN)
- **Hotel guest WiFi with IACBOX**: captive portal, branded login pages, guest access policies, VLAN integration with MikroTik
- **Network monitoring**: self-hosted **LibreNMS** server with SNMP polling, alerts and performance graphs for routers, switches and access points
- **RouterOS scripting**: automated backups, bulk config and password changes
- **Network security**: router hardening, firewall rules, network audits with Wireshark and nmap to spot unknown devices

**🛠️ IT support**
- Servers, workstations and on-site support for businesses
- MS SQL backups, local NAS and offsite cloud (Hetzner)
- PBX / VoIP telephony: **Yeastar**, **NEC**
- **Telephony / ERP integration (CTI)**: incoming calls pop up the caller's customer record from the ERP
- POS and ERP support

**💻 App development**
- **Python / Flask** web apps on top of ERP data (Pylon, MS SQL Server)
- **E-invoicing integration** with a certified provider: myDATA transmission, invoice issuing, card payments via POS
- **Python automation**: contract expiry alerts, email monitoring, renewal checks
- **Sales reports**: POS exports turned into PDF / Excel reports with VAT breakdown per rate
- Building the **G-Series** product line (see below)

**🌍 Websites**
- Websites and landing pages for hotels, villas and businesses
- Multilingual, mobile-friendly sites and personal portfolios

**🎮 Game development**
- Level design and game projects in **Unreal Engine 5**
- Megascans environments, Git LFS workflows for UE projects

### 🚀 G-Series apps

#### 🧭 GHub: the central admin

One cloud admin panel that runs the whole G-Series:
- **Customers**: one record per client, across every G-Series app
- **Subscriptions** for the cloud apps (GLink, GDepot)
- **License management** for the local apps (GBackup, GImport and more)
- **Usage rights kept separate** from payments and invoicing
- **Staff-only access** with personal accounts

#### 📦 The apps

| App | What it does |
|---|---|
| **GDepot** | Barcode stock counts and goods receipt from the phone, with cloud sync |
| **GBackup** | MS SQL backup tool for client servers, with offsite copies |
| **GImport** | Imports supplier PDF invoices into the ERP as goods receipts and new items |
| **GCall** | Mobile CRM on top of Pylon: call a client, log the task, see the calendar |
| **GShare** | Shareholder registry and beneficial owners for accounting offices |
| **GLink** | Rent a car management |
| **G-Lift** | Gym management cloud + members app |
| **GByte** | Internet / gaming cafe time billing with prepaid wallet and console control |

<sub>G-Series apps are commercial and closed-source. Get in touch for a demo.</sub>
