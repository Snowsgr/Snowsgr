## What I work on

### Networks & infrastructure

- **MikroTik / RouterOS** networks for hotels, shops and offices.
- VLANs, guest and staff isolation, and centrally managed WiFi with **CAPsMAN**.
- Multi-WAN load balancing, failover and **Starlink** connectivity.
- **WireGuard** remote access, split tunneling and PPPoE passthrough.
- Hotel captive portals and guest access policies with **IACBOX**.
- Network monitoring with **LibreNMS**, SNMP, alerts and performance graphs.
- RouterOS automation, firewall configuration and troubleshooting with **Wireshark** and **Nmap**.

### Business systems & IT support

- Servers, workstations and on-site technical support.
- **Microsoft SQL Server** backups, local NAS storage and offsite copies on **Hetzner**.
- **Yeastar / NEC** telephony and ERP caller identification through CTI integrations.
- POS and ERP installation, integration and support.

### Software development

- **Python / Flask** applications connected to **Pylon** and **Microsoft SQL Server**.
- E-invoicing integrations through a certified provider, including myDATA transmission and POS card payments.
- Automation for renewals, contract expiry alerts and email monitoring.
- PDF and Excel sales reports from POS data, with VAT breakdowns.

### Websites I've built

I've designed and built websites for hotels, villas and local businesses, as well as landing pages and personal portfolios.

- **Hospitality websites** that present properties, accommodation and guest information.
- **Business websites and landing pages** that showcase services and make it easy to get in touch.
- **Multilingual, mobile-friendly layouts** for visitors browsing on phones, tablets and desktops.

## G-Series

Business applications built around everyday operational needs.

| Application | Purpose |
| :--- | :--- |
| **GHub** | Central administration for customers, cloud subscriptions and local software licenses. |
| **GDepot** | Mobile barcode stock counts and goods receipt, with cloud synchronization. |
| **GBackup** | SQL Server backups with local and offsite copies. |
| **GImport** | Import supplier PDF invoices into the ERP as goods receipts and new items. |
| **GCall** | Mobile CRM connected to Pylon, with client calls, task logging and a calendar. |
| **GShare** | Shareholder and beneficial owner records for accounting offices. |
| **GLink** | Car rental management with e-invoicing and cloud POS integration. |
| **G Lift** | Cloud gym management and a companion app for members. |
| **GByte** | Internet and gaming café time billing, prepaid wallets and console control. |

**GHub** brings the product line together through staff accounts, shared customer records, subscription tracking and license management. Usage rights are managed separately from payments and invoicing.
